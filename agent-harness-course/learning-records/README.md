# Learning Records（学习记录）

本目录是课程的"学习 ADR"：记录你**已证明的理解**、纠正过的误解、以及因此改变的后续教学决策。
它有两个用途：① 计算你的最近发展区（下一课该教什么）；② 跨会话延续——新的导师会话先读这里。

## 何时写一条

满足任一条件就写（编号递增 `NNNN-slug.md`）：

1. 你**证明**了对某个非平凡机制的理解（答对追问、独立画出时序、手写通过测试）——不只是"看过"。
2. 你声明了**已有知识**（"我本来就会 Rust/TypeScript/…"），后续会话不再重复教。
3. 一个**误解被纠正**（例如"曾以为 toolCall 由模型执行"）——高价值信号，预示相关概念的坑。
4. 使命变化（学习目标转移）——同时更新 `../MISSION.md`。

**不写**：仅仅"读完了某课"（覆盖≠学会）；纯活动日志；术语表里已有的定义。

## 模板

```md
# {一句话标题}

{1-3 句：学到了/确认了什么，为什么影响后续教学。}

- Status: active | superseded by NNNN
- Evidence: {怎么证明的：答对什么、写出了什么}
- Implications: {解锁/排除了什么后续内容}
```
