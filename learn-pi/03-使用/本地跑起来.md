# 本地跑起来

针对本仓库 `E:\pi_north`（Windows 可用 `pi-test.ps1`）。

## 1. 环境

- Node.js **≥ 22.19**（`package.json` engines）
- 网络：首次完整 `build` 会访问 `models.dev` 等；不通时用 hydrate + offline（见下）
- 若系统代理是 `127.0.0.1:7897` 之类，**Node 不一定读 WinINET**——终端里可设：

```powershell
$env:HTTP_PROXY = "http://127.0.0.1:7897"
$env:HTTPS_PROXY = "http://127.0.0.1:7897"
```

## 2. 安装依赖

```powershell
cd E:\pi_north
npm install --ignore-scripts
```

`--ignore-scripts` 是项目推荐姿势（供应链）。

> 每次 `git merge` 上游后都要重跑一次：`package-lock.json` 变了就可能有新包或删包（1.0 删了 `session-backends`，SQLite 收进 `pi-durable`；`pi-codemode`、`pi-mcp` 和 `quickjs-wasi` 还在），
> 不装就会出现 `ERR_MODULE_NOT_FOUND`。判断是否过期：比较 `package-lock.json` 与 `node_modules/.package-lock.json` 的修改时间。

## 3. 模型数据与构建

模型 JSON 在 `packages/ai/src/providers/data/`，被 gitignore。新鲜 clone **没有**这些文件。

**有网络：**

```powershell
npm run build
```

（内部会 `generate-models` 再编译各包。）

**网络不稳，但能偶发连通：**

```powershell
npm run hydrate:model-data
npm run build:offline
```

**完全不能访问 models.dev：**

从上游 Release 下载 `pi-*-source.tar.gz`（内含已生成 model data），把 `packages/ai/src/providers/data` 拷进本仓库，再 `build:offline`。

`build:offline` 的含义是：**不重新联网生成，但本地数据必须已存在。**

## 4. 从源码启动 Pi

```powershell
.\pi-test.ps1
```

单次提示：

```powershell
.\pi-test.ps1 -p "Say exactly: ok"
```

脚本可从任意目录调用；Pi 使用**调用者当前工作目录**作为项目 cwd。

## 5. 鉴权

- API Key：如 `$env:ANTHROPIC_API_KEY = "..."`（其它厂商见 `docs/providers.md`）
- 订阅：进入交互后 `/login`

选模型：`/model` 或文档所述快捷键。

## 6. 验证构建是否完整

成功时大致应有（按根 `package.json` 的 `build` 顺序）：

- `packages/chord/dist`、`packages/tui/dist`、`packages/telemetry/dist`
- `packages/codemode/dist`、`packages/mcp/dist`
- `packages/ai/dist`（含 providers/data 拷贝）、`packages/durable/dist`、`packages/agent/dist`
- `packages/protocol/dist`、`packages/client/dist`、`packages/server/dist`
- `packages/coding-agent/dist/cli.js`（未打包入口）与 `packages/coding-agent/dist/bundle/cli.js`（`bin` 指向的打包产物）

没有 `packages/session-backends`。SQLite 存储在 `packages/durable` 里，而且不是日常 `pi` 会话的默认后端。

更快的一致性检查：`.\pi-test.ps1 --version`（源码直跑，不需 dist）。

> 历史遗留：早期笔记记录过上游遗漏 `ExtensionContext.scopedModels`（interactive shortcuts 的 `createContext` 未填充）。
> 上游已经修好。`scopedModels` 由会话注入交互模式（`src/modes/interactive/interactive-mode.ts:2218`），本仓库不需要再打这个补丁。

## 7. 检查与测试

```powershell
npm run check          # lint + 类型等（改代码后）
.\test.sh              # 非 LLM 依赖测试（Git Bash / WSL；Windows 可按 AGENTS.md 用 vitest 单测）
```

按 `AGENTS.md`：**不要**随便跑完整 `npm test`（可能触发需密钥的 e2e）。
