# 为什么 Pi 适合学习

这里的「适合初学者」不是指「零基础就能改内核」，而是：**学「现代编码 Agent 是怎么拼起来的」时，Pi 是一条清晰、可动手、可拆开的路径。**

## 1. 内核足够小，概念可数清

默认模型能力面非常克制：

- 四个核心工具：`read` / `write` / `edit` / `bash`
- 一条主循环：用户输入 → LLM →（可选）工具 → 再 LLM → …
- 几种扩展手段：Extensions / Skills / Prompt Templates / Themes / Packages

对比「内置 MCP + 子 Agent + Plan + 权限矩阵 + 后台任务」的巨型产品，Pi 更容易在脑中画出完整框图。

## 2. 分层像教科书

```
pi-ai → pi-agent-core → pi-coding-agent
pi-tui（独立）
```

你可以按层次学：

| 层 | 学到什么 |
|----|----------|
| `pi-ai` | 多厂商统一流式调用、工具 schema、模型目录 |
| `pi-agent-core` | Agent 循环、事件序列、工具并行/串行、上下文变换 |
| `pi-tui` | 终端差分渲染、组件、无闪烁刷新（与 LLM 无关） |
| `pi-coding-agent` | 产品化：会话、扩展发现、slash 命令、四种模式 |

每层都有 README，而且依赖方向单向，不会「到处互相引用」。

## 3. 例子是阶梯，不是散点

`packages/coding-agent/examples/`：

- **SDK**：`01-minimal.ts` → … → `12-full-control.ts` → `13-session-runtime.ts`
- **Extensions**：几十个模式（权限门、子 Agent、plan-mode、自定义 provider、UI overlay…）

初学者可以「抄一个最小例子 → 改一行 → 理解一个概念」，不必一开始啃万行 `interactive-mode.ts`。

## 4. 「Ask the agent」——用产品学产品

官方文档反复鼓励：让 Pi 自己帮你写 extension / skill / package。  
根 README 也说：你可以 **ask the agent to explain itself**。

这对初学者极友好：环境配好后，学习闭环变成：

1. 读一小段 docs
2. 问 Pi：「按 docs/extensions.md 给我写一个 hello extension」
3. 对照例子目录验收
4. 再读对应源码缝合点

## 5. 文档与源码对齐

- `packages/coding-agent/docs/`：面向使用者与扩展作者
- `packages/agent/docs/`：面向 harness / hooks 深水区
- Session 格式、RPC、SDK 都有独立文档

学到卡点时，通常能找到**同名概念的文档页**，而不是只能靠猜。

## 6. 可以不花钱跑测试

`AGENTS.md` 约定：非 e2e 用 `./test.sh`；suite 用 faux provider，不依赖真实 API。

你可以在没有 Key 的情况下理解大量行为契约。

## 7. 安全模型诚实、好理解

Pi **没有**内置「权限弹窗系统」。默认等于「启动它的用户权限」。

初学者反而更容易建立正确心智：

- Agent 能读你的盘、跑你的 shell，是因为你给了进程权限
- 要隔离 → Docker / Gondolin / OpenShell / 自己写 permission extension

没有「看起来很安全其实边界模糊」的假象。

## 适合学什么 / 不适合当什么

**适合：**

- 理解 coding agent 的最小完备集
- 学习如何做可扩展 CLI Agent
- 二次开发自己的工作流或产品壳

**不适合当作：**

- 「零编程基础入门 AI」教程（仍需要 JS/TS 与命令行）
- 「开箱即用企业权限与审计套件」（要自己加）

## 和「功能最全的 Agent」比，学得更快的原因

| 维度 | 巨型产品 | Pi |
|------|----------|-----|
| 概念数量 | 多且耦合 | 少且分层 |
| 改行为方式 | 常要 fork 或等官方开关 | Extension / Package 优先 |
| 运行时形态 | 常绑 IDE | TUI + SDK + RPC 都开放 |
| 省略功能 | 少 | 多（但有例子可装回） |

「省略」降低了入门噪声；「例子把省略装回来」又保证进阶时不缺参照实现。
