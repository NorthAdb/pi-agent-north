# 扩展 · 技能 · 包

## Skills（技能）

**是什么**：按 Agent Skills 约定组织的「能力包」——`SKILL.md` + 可选脚本/资源。

**解决什么**：

- 把长流程、团队规范、外部 CLI 用法，做成**按需加载**的知识
- 避免永远塞满系统提示

**典型位置**：用户或项目 skills 目录；也可用 `--skill`；可打进 package。

**文档**：`packages/coding-agent/docs/skills.md`  
**例子**：`examples/sdk/04-skills.ts`；fixtures 下大量边界用例。

**初学者练习**：写一个「生成 CHANGELOG 片段」的 skill，描述写清楚触发条件。

---

## Prompt Templates（提示模板）

**是什么**：slash 命令展开成一段提示（可带参数）。

**解决什么**：高频话术标准化（评审、发布检查、提交说明）。

**文档**：`docs/prompt-templates.md`  
**例子**：`examples/sdk/08-prompt-templates.ts`；subagent 例子里的 prompts。

---

## Extensions（扩展）

**是什么**：TypeScript 模块，拿到 `ExtensionAPI`，在加载时注册能力。

**能做的事（不完全表）**：

| 类别 | 例子 |
|------|------|
| 生命周期 | 拦截 tool call、改上下文、退出时动作 |
| 工具 | todo、提问框、子 Agent、截断输出 |
| 命令/快捷键 | 自定义 slash、键位 |
| UI | footer/header/overlay/自定义渲染 |
| Git | checkpoint、auto-commit、dirty guard |
| Provider | 自定义流式、OAuth、私有网关 |
| 安全 | permission-gate、confirm-destructive |

**文档**：`docs/extensions.md`（很长，建议配合例子读）  
**目录**：`examples/extensions/` + `examples/extensions/README.md`

**最小路径**：

1. 读 `hello.ts`（若存在）或任意最小 registerCommand 例子  
2. 复制到自己的 `~/.pi/agent/extensions` 或项目约定路径  
3. 重启 `pi`，调用你的命令  
4. 再尝试 `on("tool_call", …)` 做只读日志，最后才做 block

## Pi Packages（包）

**是什么**：把 extensions / skills / prompts / themes 捆成可安装单元。

**命令**（产品 README）：

```bash
pi install <source> [-l]
pi remove <source>
pi update --extensions
pi list
pi config   # 启用/禁用包内资源
```

`source` 可以是路径、npm、git。

**文档**：`docs/packages.md`  
**约定**：常规目录布局，或 `package.json` 里的 `pi` 字段。

**二次开发含义**：你的公司内部工作流可以「装包」而不是「人手拷文件」。

---

## Custom Provider / Models

- 已支持的 API 方言：可用 `models.json` 加模型（`docs/models.md`）
- 完全自定义协议 / OAuth：`registerProvider`（`docs/custom-provider.md`）
- 例子：`custom-provider-anthropic`、`custom-provider-gitlab-duo`

---

## 三者怎么配合（推荐组合）

| 场景 | 组合 |
|------|------|
| 教模型用内部 CLI | Skill（说明书）+ 偶尔 bash |
| 强制每次提交前检查 | Extension 钩子 + 可选 Prompt |
| 团队统一发套件 | Package 打包上述资源 |
| 接公司网关 | Custom provider extension + models |

## Ask Pi 自己写

官方文档鼓励直接让 Pi 根据 `docs/extensions.md` / `skills.md` 生成脚手架。  
这是学习闭环的一部分，不是偷懒——生成后你要能对照 API 讲解每一行。
